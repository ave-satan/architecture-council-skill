# Отрендеренные схемы

Помещай сюда SVG или PNG, если целевая система документации не отображает
исходный формат. Редактируемые исходники в соседних каталогах остаются
нормативными.

В `evidence/package-validation.md` зафиксируй инструмент, результат render и
ручную визуальную проверку. Наличие файла без такой проверки не доказывает
корректность схемы.
